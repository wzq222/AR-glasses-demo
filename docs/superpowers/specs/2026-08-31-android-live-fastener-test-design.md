# Android 手机实时检查点测试设计

## 目标

在当前通过ADB连接的华为P20 Pro上安装一个内部测试APK，使用手机后置摄像头近实时检测全图紧固件候选，
叠加候选框、置信度、推理耗时和帧率。该版本用于验证端侧模型能否运行、画面交互是否可用以及候选检测的
实际表现，不作为生产验收。

## 能力边界

- 当前ONNX只提供全图紧固件候选，不提供防松线两侧端点或松动状态。
- 画面必须固定显示“松动状态：无法判断”，不得根据目标框、颜色或单张图推断正常/松动。
- 当前模型的同源内部验证为precision 0.641、recall 0.584，不显示“高准确率”或安全结论。
- 模型文件位于Git外数据目录，只在本机构建时打入APK，不提交模型和现场图像。
- 安装命令必须明确指定手机序列号`TPC7N18604005991`，不得使用无序列号的`adb install`。

## 架构

主界面增加“手机实时检测”入口。`LiveInspectionActivity`使用CameraX建立后置摄像头预览和
`ImageAnalysis`流；分析器采用`KEEP_ONLY_LATEST`，同一时刻只运行一个推理，最大约2 FPS，避免积压和
发热。`OnnxFastenerDetector`负责640×640 letterbox、RGB归一化、ONNX Runtime执行、双类别合并、
置信度过滤和类别无关NMS。`DetectionOverlayView`把模型坐标映射回预览画面。

模型通过环境变量`CRRC_VISION_MODEL_DIR`指向Git外目录。Gradle将该目录作为生成时assets源；模型不存在
时APK仍可构建，但实时页面明确显示“模型未打包”，不崩溃。

## 界面

- 全屏后置摄像头预览。
- 顶部状态条：模型状态、候选数、单次推理毫秒、近似FPS。
- 候选框：橙色矩形，标签为“候选点 0.xx”。
- 底部固定安全提示：“松动状态：无法判断（状态模型和真实阈值尚未就绪）”。
- 返回按钮退出实时页面并释放相机、线程和ONNX会话。

## 错误处理

- 相机权限拒绝：保留页面并给出授权提示。
- 模型缺失或初始化失败：停止分析，预览仍可打开并显示错误。
- 单帧推理异常：丢弃该帧、记录错误，不阻塞后续帧。
- 页面暂停或退出：解绑CameraX并关闭推理线程和ONNX会话。
- 设备过慢：通过单帧背压和500ms节流自动维持可交互性。

## 验证

1. JVM单测验证letterbox逆映射、双类别分数合并、阈值和NMS。
2. 完整Python回归，确保数据与状态审计链不受影响。
3. `clean testDebugUnitTest assembleDebug`构建带模型APK并记录SHA-256。
4. 使用手机序列号安装、授予相机权限、启动实时页。
5. 读取logcat和进程内存，确认模型加载与至少一次推理成功；截取手机画面验证预览、框和安全提示。
