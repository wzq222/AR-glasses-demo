# 带防松标记检查点合成与全图混合设计

## 目标

用现场实拍作为视觉参考，生成可追溯的紧固件局部照片，并将其以适度变换混合到真实全图中，补充
`NORMAL`、`SLIGHT_LOOSE`、`OBVIOUS_LOOSE` 三种状态的训练样本。合成数据只作为训练候选，不能进入
验证集、sealed-test 或 formal truth，也不能单独支撑生产准确率结论。

首批试点固定为12个独立实拍参考检查点，每个参考点生成三种状态，共36张局部图；通过质检后再合成
全图。试点目标是验证生成、标签、变换、合成和隔离链路，不追求一次性扩量。

## 核心选择

采用“参考图生成真实局部底图 + 确定性状态构造 + 可审计全图合成”的混合路线。

- ImageGen负责基于实拍参考生成写实的局部检查点，保持紧固件类型、相机视角、工业污渍、光照和材质。
- 状态差异由明确的线段端点和相对角度描述；同一参考点的三种状态共享相同的设备外观和背景语义。
- OpenCV负责适度的几何、光照和成像变换，以及局部图到真实全图的合成和标签坐标变换。
- 所有随机过程必须由种子驱动，生成物记录来源哈希、提示词、参数、标签和审核结果。

选择该路线是为了同时获得照片真实性、状态可控性和标签精确性。完全由生成模型直接输出三种状态容易
改变设备结构并漂移标签；纯程序绘制又容易形成明显的合成域。

## 参考点选择

从已复核的 `marked-point-v1.4` 开发资产选择12个独立场景，每个场景最多一个参考点。选择覆盖：

- 六角螺栓/螺母、接线柱、管路接头和法兰连接等不同结构；
- 红、黄两类常见防松标记；
- 正视、斜视和小尺度目标；
- 清洁、轻污渍、反光和局部阴影等现场成像条件。

排除严重模糊、严重遮挡、边界截断、锚点归属不清和原始状态无法判断的参考点。参考裁剪必须保留
紧固件周围足够上下文，不能只截取一条色线。

## 局部图生成与三状态标签

每个参考裁剪生成一张写实局部底图。提示词要求保留参考图中的紧固件类型、材质、机柜环境、透视、
污渍和光照，只允许清理身份标识和不可控文字，不添加新设备或额外紧固件。

每个局部样本包含：

- `fastener_bbox_xyxy`：检查点目标框；
- `fixed_segment_xyxy`：固定侧防松线端点；
- `moving_segment_xyxy`：运动侧防松线端点；
- `anchor_xy`：旋转/位移的物理锚点；
- `state`：`NORMAL`、`SLIGHT_LOOSE` 或 `OBVIOUS_LOOSE`；
- `relative_angle_deg` 和 `relative_offset_px`；
- `visibility`、`occlusion_ratio` 和 `review_status`。

状态定义以相对几何为准，不把颜色本身当作松动证据：

- `NORMAL`：两段标记在锚点附近连续或方向一致，角度与位移在现场正常容差内；
- `SLIGHT_LOOSE`：运动侧标记产生清晰但较小的相对角度或位移，仍能确认属于同一检查点；
- `OBVIOUS_LOOSE`：相对角度或位移明显越过轻微区间，且两段标记和锚点仍可见。

试点阶段不把角度阈值固化为生产阈值。配置只提供合成区间，默认分别为正常 `0–3°`、轻微 `6–12°`、
明显 `18–35°`；后续必须用受控真实松动采集重新标定。

## 适度变换

变换分为两类，均由确定性种子产生。

不改变状态语义的全局变换：

- 旋转不超过 `±8°`、尺度 `0.85–1.15`、透视角点位移不超过边长的 `4%`；
- 亮度 `0.8–1.2`、对比度 `0.85–1.15`、色温轻微偏移；
- JPEG质量 `75–95`、轻微高斯噪声、模糊核最大 `3×3`；
- 遮挡比例不超过目标框的 `12%`，且不得同时遮住两段标记或锚点。

改变状态的局部变换只能作用于运动侧标记，围绕已标注锚点执行。禁止把整张局部图或整个紧固件随机旋转
来伪造松动；禁止在变换后依赖旧标签。所有端点、框和锚点必须用同一变换矩阵更新并做边界校验。

## 全图合成

合成背景只来自train场景，且优先选择没有目标或目标稀疏、结构清晰的真实全图。局部图贴入前进行尺度、
透视、色调和噪声匹配，使用软掩膜、Poisson或多频段融合降低边缘接缝。每张背景最多新增三个检查点，
同一源局部图不能在同一全图重复出现。

放置位置必须满足：

- 位于合理的机械连接表面，不能悬浮在空气、线缆空隙或文字标签上；
- 与原有检查点和图像边界保持安全距离；
- 最终目标短边至少12像素，合成缩放不能破坏两段标记的可见性；
- 所有框、线段端点和状态标签按合成单应矩阵转换。

## 质量门

每张局部图和合成全图必须通过以下门槛：

1. **结构门**：紧固件、锚点和两段标记均存在，且没有多余螺母、融化金属、断裂透视等生成缺陷。
2. **状态门**：基于端点重算相对角度/位移，结果必须落入声明状态区间；无法判断则标为`REJECTED`。
3. **标签门**：框和关键点位于图内，掩膜覆盖目标，变换前后反投影误差不超过2像素。
4. **合成门**：接缝、重复纹理和亮度突变不过阈值，放置位置符合机械语义。
5. **隔离门**：引用来源和背景均为train；与val/sealed-test按场景ID和pHash去重；formal truth哈希不变。
6. **模型审核门**：Codex对缩略全图和高清局部做独立审核。疑难项保持`UNCERTAIN`或`REJECTED`，不自动晋级。

试点36张局部图的最低通过条件为：三状态各至少8张通过、总通过率至少75%、零隔离违规、零标签越界。
全图试点的最低通过条件为：至少24张合成图通过，且每种状态至少6张。未达门时只回修失败桶，不盲目扩量。

## 防过拟合策略

- 以真实数据为主，首轮训练中合成样本占每个batch不超过30%；
- 同一参考点的所有派生图只能进入train，且按`source_reference_sha256`分组采样；
- 控制每种结构、颜色、状态和背景的最大占比，避免单一红线或单一机柜主导；
- 训练损失对合成样本使用可配置权重，默认0.5；
- 验证、阈值选择、早停和最终报告只使用真实val，sealed-test继续封存；
- 分别报告真实val性能、合成训练消融和各错误桶，合成集上的高分不能作为能力结论。

## 失败处理

生成失败、结构漂移、状态不清或接缝明显的样本保留清单和原因，但不进入训练目录。流水线可重跑单个
参考点或单个状态，不覆盖已通过版本。任何formal truth哈希变化、数据跨split、标签不可逆转换或输出目录
不在Git外根目录的情况都立即终止。
