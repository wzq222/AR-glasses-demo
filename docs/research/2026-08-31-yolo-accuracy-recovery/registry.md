# Source Registry

1. SAHI paper: https://arxiv.org/abs/2202.06934 — primary paper; sliced fine-tuning/inference for small objects.
2. Focal Loss paper: https://arxiv.org/abs/1708.02002 — primary paper; foreground/background imbalance.
3. OHEM paper: https://arxiv.org/abs/1604.03540 — primary paper; hard-example selection.
4. MobileNetV3 paper: https://arxiv.org/abs/1905.02244 — primary paper; hardware-aware mobile backbone.
5. DINOv3 official page: https://ai.meta.com/research/dinov3/ — official feature/backbone scope.
6. DINOv3 model card: https://github.com/facebookresearch/dinov3/blob/main/MODEL_CARD.md — official model and usage boundary.
7. Ultralytics tiled-inference guide: https://docs.ultralytics.com/guides/sahi-tiled-inference — official implementation guidance.
8. Local validation and machine reports listed in `research-notes/local-evidence.md`.
