# 防松线松动状态评估与阈值研究计划

- 研究问题：在缺少真实松动负样本的前提下，如何定义可审计的防松线状态评估协议、临时工程阈值和后续正式标定方法；现有公开模型与算法能提供哪些可复用证据。
- 受众：中车眼镜项目管理者、算法与移动端工程师。
- 时效：截至2026-09-01，优先论文、标准/官方资料、作者代码及本项目真实数据证据。
- 范围：二维手机/眼镜图像中的螺栓、螺母防松见证标记；不把扭矩值、预紧力或结构安全结论等同于图像状态。
- 输出：简报，附来源登记、明确局限和可执行的验证设计。
- 风险等级：高。误把松动判为正常可能影响现场安全，任何临时阈值必须保留拒判与人工复核。
- 使用深度研究的理由：需要综合视觉测量、紧固件松动检测、公开模型和本项目数据现状，单一来源无法支撑选型。

## 研究线程

1. 物理语义与公开算法：查明防松见证标记能证明什么、不能证明什么，以及公开视觉松动检测采用的特征。
2. 模型与评估：比较目标检测、分割/关键点、基准图配准、时序变化检测和端到端分类的证据与适用条件。
3. 本地证据：核对现有19个真实参考点、二审结果、合成三态数据和状态融合代码，确定现在能否计算阈值。
4. 阈值协议：提出不依赖虚假精度的临时警戒阈值、拒判带和后续受控成对标定/独立测试方案。

## 完成标准

- 至少覆盖三类独立证据：同行评审论文或作者论文、官方/原始技术资料、本项目可复现实测。
- 明确回答是否可以在没有真实负样本时给出“生产阈值”。
- 给出临时阈值的数学定义、适用边界、人工审核路径，以及把它升级为生产阈值所需最小数据。
- 不把公开论文模型的指标直接搬成当前设备/场景的准确率。
