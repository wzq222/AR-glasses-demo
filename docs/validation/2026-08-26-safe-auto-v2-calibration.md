# 安全自动标注V2校准闭环

## 目的

用少量代表图验证`首轮全图扫描 → 候选判定/补框 → 隐藏首轮结论二审 → 完整图COCO组装 → 银标门`
是否真正闭环，避免把流程缺陷扩散到100张。

## 校准范围

从`selection-v2`选择4个独立场景：

- 图41：清晰宽景，旧流程只有1个候选，测试高清漏检扫描和补框二审；
- 图116：清晰近景，测试重复框与边界截断排除；
- 图153：真实运动模糊，测试合理的`uncertain`；
- 图160：两个清晰目标、四个重复/子框候选，测试候选去重和直接完成。

校准规则：只标注完整可界定的巡检连接；防松标记不是`fastener`入选的必要条件；图像边界截断、
远距离微小背景件和同一目标的重复子框排除；模糊、遮挡或类别无法确认时保留`uncertain`。

## 结果

- 首轮：图116、160直接完整；图153因运动模糊不确定；图41发现4个明确漏检，进入
  `pending_second_pass`，没有被错误降级为`uncertain`。
- 二审：图41的4个卡箍紧固连接全部由隐藏首轮结论的高清叠加图确认，并收紧最终边界。
- COCO组装：3张完整图、7个接受框、1张不确定图；train 2场景、val 1场景。
- `instances.reviewed.json` SHA-256：
  `6E9A4B4B2F7985712D91206962B3A8F2F0041C6EA5312D9900954392DC81C69F`。
- 正式真值SHA-256保持：
  `B659FC8160BD7C49491BA4C560E1AF047CA837E54EE93E79826FEBAABCB0F001`。

银标门按预期拒绝，且拒绝原因只有`INSUFFICIENT_TRAIN_GROUPS`和`INSUFFICIENT_VAL_GROUPS`；没有
未决候选、非法框、类别或场景泄漏错误。这证明校准闭环的数据契约已打通，但尚未达到训练数量门槛。
