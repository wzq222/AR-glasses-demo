# 中车眼镜全图预标注质量审计（2026-08-25）

## 结论

`hsv-line-v2` 可作为红/黄色防松标记的候选召回器，但不能直接生成训练真值。本次候选级分层复核精确率为
60.89%，低于预先规定的80%训练门，因此不启动D-FINE训练，也不把这批标签称为已标注数据集。

## 数据与拆分

- 原图：482张，均为2000×1500，精确重复0张。
- 拍摄跨度：2024-05-29 11:14:56—11:57:43，属于单次现场采集。
- 近重复隔离：按3秒时间邻接或pHash汉明距离不超过4合并为177个场景组。
- 拆分：训练424张、内部验证58张；场景组跨集合泄漏为0。
- 当前数据没有受控的“松动/正常”真值，只能用于建立候选检测和标注流程，不能据此报告松动分类准确率。

## 抽样与复核方法

- 按候选数排序并跨分位抽取60张，覆盖0候选、低候选和高候选画面。
- 抽样中共有257个候选；为每个候选生成带上下文的独立裁剪，并逐一标为`accept`、`reject`或
  `needs_manual`。
- 接受151、拒绝97、需人工确认9、未复核0。
- 候选级精确率：`151 / (151 + 97) = 60.89%`；需人工项不进入分母。
- 全图漏标观察：60张中保守观察到至少12张仍有明显但未被候选框覆盖的标记，观察下界20%。该值不是
  完整召回率，因为本批数据没有逐图穷举真值。

主要失败形态为锈蚀/红色结构色、黄色警示贴和强光、非紧固件上的红色线缆或涂装，以及同一紧固件的
断裂色标产生多个候选。暗光会同时造成漏检和低置信度；管接头上的真实防松线可被检出，但会与锈蚀管路
混淆。

## 训练门判断

**FAIL。** 当前1,993个annotation均是自动候选，只有抽样257个完成AI复核，而且抽样精确率低于80%。
训练脚本必须拒绝未复核annotation。下一批动作应先建立人工确认的紧固件框真值（建议先做80—120个
场景组），再用色标端点作为框内关键点预标注；不能通过继续收紧HSV阈值来伪造训练就绪状态。
