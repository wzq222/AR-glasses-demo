# 中车眼镜D-FINE-N训练就绪判断（2026-08-25）

## 当前判断

训练门拒绝启动。当前COCO候选共1,993个，其中抽样复核接受151、拒绝97，其余1,745个仍未形成可训练真值；
已复核候选精确率60.89%，也低于80%下限。

这不是GPU或环境故障。RTX 3060 Laptop GPU可作为后续D-FINE-N首轮训练设备；当前阻塞是标签质量。
因此本轮没有安装大体积CUDA训练依赖，也没有生成一个会误导后续验证的checkpoint。

## 强制门槛

`ml/scripts/train_dfine.py`在加载COCO和候选级复核索引后，必须同时满足：

1. annotation全部完成接受/拒绝复核；
2. 已复核精确率不低于0.80；
3. 至少存在一个接受标注。

不满足时脚本以非零状态退出，并把机器可读报告写入私有资产目录的
`runs/training-readiness-v1.json`。

## 达门后的固定训练方案

- 模型：官方Apache-2.0 D-FINE-N固定提交，不使用DINOv3或DEIMv2作为APK依赖。
- 类别：单类`marked_fastener`；输入640；AMP；固定seed；输出仅写Git外资产目录。
- 设备：RTX 3060 Laptop GPU 6GB，初始batch 4、梯度累积4、最多20 epoch；以场景组隔离的内部验证集
  记录AP和逐场景漏检。
- 训练后仍需独立现场采集的test集；现有单次44分钟采集不能承担最终泛化结论。
